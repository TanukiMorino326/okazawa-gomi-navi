# お気に入り v01：配置・試作・検証報告

作業ブランチ：feature/item-search。ローカル試作。GitHubへのpush、本番反映、外部サービス追加は行っていません。

## 推奨位置と実装

2列表示では「古紙類」の右隣、横長の「特別な出し方」の直前を推奨し、その位置に試作しました。既存の7つの通常分類の順番、8番目の特別な出し方、代表例・袋見本を維持できます。「お気に入り」は分別区分ではないため、星のアイコンと「保存した分別案内」で区別しています。

1列になる狭い画面では「古紙類→お気に入り→特別な出し方」の順です。先頭へ置くより、従来の分類選択の順序が変わりにくい配置です。

## 保存・一覧・削除

- 検索結果と詳細の節に「☆ 保存」を追加。保存済みは「★ 保存済み」と表示し、同じ参照の重複を防止。
- 「お気に入り」カードから一覧へ。案内を押すと元のカテゴリーまたは該当節へ直接移動。戻るとお気に入り一覧の選んだ案内へ復帰。
- 一覧の「削除」で、その登録だけを削除。全削除・編集・並べ替え・自由入力などは追加していない。
- 未登録時には保存方法を短く案内。
- 検索から保存した「対象外・注意の説明」「分別先未確定」は一覧でも区別を維持。詳細から保存したものは「保存した案内」と表示。保存が分別先の確定を意味する表示にはしない。

## データ保護

保存先は既存設定とは別のlocalStorageキー `okazawa-gomi-sort-favorites-v1`。アカウント・外部DB・通信は不要。
保存するのは既存データ内の参照と、元の文が変わっていないか照合するための日本語・英語の控え。表示時には現行の分類データを読む。品目名や独自の分別方法を自由入力させる機能はない。

参照先の文が変わった場合は、古い文を表示したり別の節へ自動で付け替えたりせず、「案内が更新されたため開けません」と表示し、削除・検索からの保存し直しを案内する。
保存領域の利用不可、容量不足、破損・未対応形式では保存成功と表示せず、既存の保存データを無条件で上書きしない。検索と分類閲覧は継続できる。

保存は同じ端末・ブラウザー・URLの範囲。PCとGalaxy、本番と確認用プレビューは別の保存領域で、自動同期・移行はしない。ブラウザーのサイトデータを削除するとお気に入りも消える。今回、同期・移行機能は追加していない。
