# Okazawa Gomi 品目検索 v02：改善・検証報告

状態：既存の `feature/item-search` ブランチでのローカル試作。GitHubへのpush、本番反映、外部API連携は行っていません。

## 変更したこと

カテゴリー名を分別先と取り違えにくくするため、検索結果の主見出しを次の3種類にしました。

| 表示 | 根拠と意味 |
| --- | --- |
| 品目・出し方の案内 | 既存の代表品目や節見出しの品目名に正規化後の完全一致。条件なしで出せるという断定ではない |
| 対象外・注意の説明 | 既存の「注意すること」にある一致文。対象外のほか条件も含むため、すべてを対象外と断定しない |
| 関連説明（分別先未確定） | 部分一致やその他の説明。記載箇所を案内し、分別先は確定しない |

カテゴリー名は小さな「掲載先」に変更。対象外・注意は左の太線と薄い背景、関連説明は破線で区別します。色だけに頼らず、文字でも区別できます。一致文は省略せず表示します。

スプレー缶は、燃やせないごみ内の品目の案内が先、その後に缶・びん内の対象外説明が出ます。同じカテゴリーに一致する注意文があれば、代表品目より注意文を優先して表示します。一般的な言語推論や新しい品目別辞典による判定は加えていません。

検索結果を押すと、節を特定できる場合はその節へ直接移動します。詳細から戻ると、検索語・検索結果・押した結果へのフォーカスを復元します。従来版で検索語だけが残り結果が再表示されない不具合も修正しました。

8カテゴリー、分類別の代表例、袋見本リンク、分類データは維持しています。`app.js`、`index.html`、`sort-data.js`、元の `style.css` は今回変更していません。外部API、追加ライブラリ、検索語の保存・送信はありません。

## 残る懸念と次の確認

- Galaxy実機のキーボード、端末の文字拡大、縦横の操作感、USB接続・ドライバーは未検証です。
- 現在の分類データは完全な品目辞典ではありません。読み仮名や同義語の追加はしておらず、「でんち」と「電池」は別の語です。
- ラベルは既存データ内の記載場所と品目名の一致に基づきます。「対象外・注意の説明」は必ずしもその品目全体の対象外判定ではありません。
- 品目がカテゴリー内の複数の節に現れる場合は、注意文を優先して一つの結果を表示します。詳細画面には他の節もそのまま残ります。
- 既存の公式分別情報を全面的に再照合したものではありません。元の説明を保持し、検索一致から新しい分別判断を生成しない範囲を検証しました。
- 本番承認前に実機で誤認と操作感を確認する必要があります。GitHubへのpush・本番反映は引き続きミツルさんの承認待ちです。
