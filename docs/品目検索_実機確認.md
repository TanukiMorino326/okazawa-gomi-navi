# Galaxy S24 FE：品目検索 v02 の確認（約5分）

これは本番に触れない確認用です。実機の確認結果はまだ記録していません。

## 開く方法：外部公開しないUSB接続を推奨

PC内だけで待ち受ける専用プレビューを、USBケーブルでGalaxyのChromeから開きます。Wi-Fiへの公開、ルーター・ファイアウォールの変更、GitHubへのpushは不要です。

1. PCで、隣の `OkazawaGomi_品目検索_実画面プレビュー` フォルダーにある `プレビュー起動.cmd` を開き、そのウィンドウを起動したままにします。PCの確認用URLは `http://127.0.0.1:4187/okazawa-gomi-navi/` です。
2. Galaxyで「開発者向けオプション」の「USBデバッグ」を有効にし、データ通信できるUSBケーブルで自分のPCにつなぎます。Galaxyに確認が出たら、接続した自分のPCであることを確かめて許可します。開発者向けオプションの場所が分からない場合は、そこから一段階ずつ案内できます。
3. PCのChromeで `chrome://inspect/#devices` を開き、「Discover USB devices」を有効にします。Galaxyの機種名が表示されることを確認します。
4. 同じ画面の「Port forwarding」で、左のPortに `4187`、右の宛先に `localhost:4187` を入力し、「Enable port forwarding」を有効にして確定します。
5. GalaxyのChromeで `http://localhost:4187/okazawa-gomi-navi/` を開きます。上部に「PREVIEW 品目検索 v02」「本番ではありません」があることを確認します。本番のホーム画面アイコンは使いません。
6. 確認後はプレビューのタブを閉じ、PCのサーバーを Ctrl+C で終了します。ポート転送・USBデバッグは、今回だけ有効にした場合は無効に戻します。

この手順はChrome公式のAndroid遠隔デバッグとUSBポート転送に基づきます。Galaxyの接続認証・ドライバーの状態によって追加設定が必要な場合があります。USB接続自体はこの作業では実行していません。

- [Chrome公式：USBポート転送](https://developer.chrome.com/docs/devtools/remote-debugging/local-server#port-forwarding)
- [Chrome公式：Android接続の準備](https://developer.chrome.com/docs/devtools/remote-debugging)

Node.jsが見つからない、4187番が使用中、Galaxyが表示されない場合は、その表示を教えてください。設定を手当たり次第に変える必要はありません。

| 操作 | 確認すること |
| --- | --- |
| 日本語で「分別」を開き、何も入力せず眺める | 8カテゴリーがあり、従来どおり選べる。燃やせるごみ・生ごみ・燃やせないごみの詳細に代表例と袋見本リンクがある |
| 「スプレー缶」を検索 | 「品目・出し方の案内／掲載先：燃やせないごみ」と「対象外・注意の説明／掲載先：缶・びん」が別の見た目で出る。後者には「対象外で、燃やせないごみ」の文がある |
| 最初の結果を押す →「カテゴリー一覧へ」で戻る | スプレー缶の節へ移動し、手順と注意を読める。戻ると検索語と2件の結果が残る。もう一方の結果は缶の対象外説明へ進む |
| 「哺乳びん」を検索 | 「対象外・注意の説明」と「燃やせないごみです」の原文が出る。「缶・びんで出せる」と読める表示になっていない |

| Englishに切替え、`aerosol cans` を検索 | Item disposal guidanceとExclusions & precautionsを区別できる。結果から詳細へ進み、戻れる |
| 端末を縦・横にして、検索結果をスクロール | 横にはみ出さず、キーボード表示中も入力・消去・結果を選べる。文章を最後まで読める |

余裕があれば、端末の文字サイズを大きくして再確認し、確認後は元へ戻してください。PCで行ったCSSの200%拡大テストとは別の検証です。
